mindspore.mint.equal
=====================

.. py:function:: mindspore.mint.equal(input, other)

    逐元素比较两个输入tensor是否相等。

    .. note::
        `input` 和 `other` 遵循隐式类型转换规则，使数据类型保持一致。

    参数：
        - **input** (Tensor) - 第一个输入tensor。
        - **other** (Tensor) - 第二个输入tensor。

    返回：
        Bool型tensor
